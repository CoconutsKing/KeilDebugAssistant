新手教程 从第一次连接到滑条调参，跟着这 5 步完成
01

开启 Keil 接口

打开 Keil → Edit → Configuration → Other，在 UVSOCK (TCP/IP) Settings 勾选 Enabled。

每个窗口设独立端口，例如第一个 4823、第二个 4824，点击 OK。工具自动发现所有监听端口。若仍未生效，保存工程后重新打开对应 Keil。

02

连接并启动调试

先编译工程、配置好 Keil 调试器并连接供电的开发板。在上方选择对应 Keil 窗口，点击“进入 Debug 并运行”，工具会等待初始化完成后执行 Run；目标已暂停时显示“继续运行”。也可点击“连接 Keil”，在 Keil 中手动启动调试。

绿灯闪烁表示调试已连接，红色“断开连接”可停止工具连接；启动过程中可取消后续指令。黄灯表示连接中或等待 Debug，红灯表示未连接或失败，下方显示原因。进入失败不会继续执行 Run；遇到断点时按实际状态显示暂停。多个窗口请指定要操作的工程。

03

导入或搜索变量

核对上方醒目的 Watch 来源，点击“导入 Watch”。在 Keil 保存工程配置后，可同步 Watch 列表。

点击“添加变量”搜索名称 / 类型。选择数组或结构体后，可点击“批量选择显示成员”按需勾选；也可用下拉逐层选择单个成员。已有组件用“选择显示成员”调整，未勾选的成员不占用该组件的采样时间。请先编译工程，变量列表需要 AXF 调试信息和 ARM GNU 的 readelf 工具。

04

滑条调参

设置最小值、最大值和步长后保存；拖动滑条松开即写入，鼠标悬停时滚轮可直接调节。也可用 ± 或输入数字按回车。

实际值会回读刷新。“切换上次值”可在两个目标之间往返。每个成员可单独设置范围，新建时记住上次设置。

要带回代码时，选择组件的“复制范围”，点击“复制 C++ 数组”；会读取整个选定范围，包含未显示成员，结构体使用 .成员名 = 数值，保留多维数组层级；指针、非数字和不可读成员会跳过并提示，数组缺失项以 {} 占位。读取中可取消，浏览器限制剪贴板时可在文本窗口复制。

数组或结构体调好后点击“保存当前数据”，保存当前显示的数值成员。退出 Debug 或关闭工具后记录仍保留；再次进入 Debug 后点击“恢复已保存数据”即可逐项写回。恢复前会检查全部成员的类型、范围与可写状态，按钮下方显示进度和结果；再次保存会替换该组件上一次记录。

05

整理并带走面板

数组组件内输入索引后按回车，或点击 ‹ / ›，即可切换要监视的元素；“整个数组”返回整组。嵌套数组可分别选择各维索引。尺寸、位置和对应成员设置保留，保存数据与历史仍对应各自索引。

点击“编辑布局”，拖动标题移动组件、右下角改变大小。齿轮可更换变量，× 删除变量。组件可拖到画布最左侧，完成排版后按原位置保存；折叠侧栏的图标居中显示；“收起顶部设置”可只保留变量监视，再点“展开顶部设置”恢复。

主题、布局和历史自动保存在 userdata；复制整个工具目录即可迁移，也可导出 / 载入面板。先点 stop.bat 关闭工具。教程可点右上角 × 关闭，从左侧“新手教程”重新打开。
