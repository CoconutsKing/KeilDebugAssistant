新手教程 从第一次连接到滑条调参，跟着这 5 步完成
01

开启 Keil 接口

打开 Keil → Edit → Configuration → Other，在 UVSOCK (TCP/IP) Settings 勾选 Enabled。

每个窗口设独立端口，例如第一个 4823、第二个 4824，点击 OK。工具自动发现所有监听端口。若仍未生效，保存工程后重新打开对应 Keil。

02

连接调试窗口

在上方选择“自动”，点击“连接会话”，然后在 Keil 点击 Debug → Start/Stop Debug Session。

多个窗口同时调试时，在“Keil 窗口”选择指定工程。自动模式保留当前正在调试的窗口，退出 Debug 后寻找其他窗口。

03

导入或搜索变量

核对上方醒目的 Watch 来源，点击“导入 Watch”。在 Keil 保存工程配置后，可同步 Watch 列表。

点击“添加变量”搜索名称 / 类型，选择数组或类可展开全部数值成员，也可逐层选择单个成员。请先编译工程，变量列表需要 AXF 调试信息和 ARM GNU 的 readelf 工具。

04

滑条调参

设置最小值、最大值和步长后保存；拖动滑条松开即写入，鼠标悬停时滚轮可直接调节。也可用 ± 或输入数字按回车。

实际值会回读刷新。“切换上次值”可在两个目标之间往返。每个成员可单独设置范围，新建时记住上次设置。

05

整理并带走面板

点击“编辑布局”，拖动标题移动组件、右下角改变大小。齿轮可更换变量，尺寸和位置保持不变；× 删除变量。

主题、布局和历史自动保存在 userdata；复制整个工具目录即可迁移，也可导出 / 载入面板。先点 stop.bat 关闭工具。无需硬件可选“演示数据”体验。

变量监视

0 个变量

拖动组件标题旁的 ⠿ 移动，拖动右下角 ◢ 调整大小，松开自动保存。完成后点击“完成排版”。

滑条松开、滚轮或增减按钮会写入并回读。成员依次读取，更新时间见各行。
