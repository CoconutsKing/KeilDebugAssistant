# Keil Debug Assistant V2.1.0

V2.1.0 增加 GitHub 后台静默更新、自动更新开关和手动更新入口，支持数组 / 结构体参数保存与恢复，并修复恢复参数时扩展 Watch 写入响应慢导致的超时。

作者：oyhy。Keil µVision 本地变量监视与滑条调参工具。

安装 Node.js 20+ 后，解压发行包，双击 **start.cmd**，网页内按五步新手教程连接；双击 **stop.bat** 关闭。无需安装 npm 依赖。也可运行 `npm start`。

## 主要功能

- 自动发现多 Keil 窗口和任意 UVSOCK 监听端口；自动选择 Debug 会话，也可固定窗口。
- 已连接 Debug：绿灯闪烁、红色“断开连接”；连接中 / 等待 Debug：黄灯闪烁、绿色“取消连接”；未连接 / 失败：红灯闪烁、绿色连接按钮，失败原因显示在连接区下方。失败时可点击“断开连接”停止重试。
- 各工程保存独立面板，切换窗口时清除旧实时数据，并拒绝过期会话写入。
- 导入 Watch、搜索名称/类型、下拉选择数组与类成员、一次展开数值成员。
- 选择数组 / 结构体后，点击“批量选择显示成员”；已添加组件可点击“选择显示成员”调整。支持搜索、全选当前结果、清空当前结果、逐项勾选；未选成员不参与该组件的周期采样，清空可暂停该组件读取。选择随工程面板保存并支持导入导出。
- 滑条松开写入，鼠标悬停滚轮调参、加减按钮、输入回车，立即回读实际值。
- 每个数值行可在上一个输入值与新值之间切换，记录自动保存。
- 数组 / 结构体组件可“一键保存当前数据”和“恢复已保存数据”。保存当前显示的数值成员并按工程保存在本地，退出 Debug 或重启工具后仍保留；再次进入 Debug 后手动恢复，逐项写入并回读确认。恢复前检查成员、类型与范围，隐藏了已保存成员时需先恢复原勾选范围。保存失败保留上次记录，恢复中断会显示已确认完成的项数。
- 整型数值行勾选“十六进制”显示 `0x…`，取消显示十进制；悬停实际值同时查看两种进制，选择随面板保存。输入和滑条仍按十进制调节；负数十六进制显示为 `-0x…`。
- 新建范围/步长记忆，单成员范围设置，收藏筛选，JSON 面板导入导出。
- 组件自由移动缩放，更换变量后保持尺寸位置，超出内容内部滚动。
- 五种主题、可折叠侧栏、顶部 Watch 来源、内置新手教程。
- 左侧“软件更新”：后台检查 GitHub 正式版、校验并下载更新包，支持自动安装和手动更新；连接 Keil 或编辑面板时延迟安装。

多个 Keil 窗口必须分别使用不同 UVSOCK 端口。在每个窗口的 **Edit → Configuration → Other** 设置 Enabled 和独立端口（例如 4823、4824），或使用官方 `UV4 project.uvprojx -s 4824` 启动。相同端口无法同时由两个窗口监听。自动模式保留当前有效 Debug 会话，退出后再寻找其他窗口；多个窗口都在 Debug 时可手动选定。

数组/结构体类型来自所选工程的 AXF DWARF，数值从 Keil 读写；需要先编译工程并保证 `arm-none-eabi-readelf` 在 PATH 中。缺少调试信息时退回 Watch 已配置项。兼容接口和扩展接口均保留；不自动解引用任意指针。单组最多展开 512 个数值成员、8 层。

## 软件更新

在左侧打开“软件更新”，可查看当前版本和 GitHub 正式版，点击“检查更新”立即查询。默认开启“自动下载并更新新版本”；取消勾选后仍会检查版本，可按需点击“下载更新并重启”。设置自动记忆。

启动约 15 秒后首次检查，此后每 6 小时检查一次。检查和下载与 Keil 采样分开执行，解压校验在独立线程完成；网络失败只在更新窗口显示，不弹出窗口、不影响调参。查询使用公开的 [GitHub Releases 接口](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)，API 限流时尝试同仓库的正式版跳转地址，不需要 GitHub 登录或访问凭证。

连接 Keil 期间只在后台下载。手动断开工具与 Keil 的连接、完成面板编辑后，更新器才会备份旧程序、替换程序并重启本地工具；更新不会退出 Keil Debug 或自动改写目标内存。手动更新也遵守此规则。浏览器会自动重载新版页面，重新连接 Keil 后即可继续调试。

更新包必须来自此仓库的正式 Release，附件名称为 `KeilDebugAssistant-v版本号-windows.zip`，并带同名 `.sha256` 文件。更新器验证 SHA256、ZIP 文件边界、路径白名单及包内版本，拒绝预发布版、降级、用户数据文件与异常路径。安装过程中保留 `userdata/`，包括 PID 保存记录、面板、历史、布局、主题和更新设置；新程序启动验证失败会回滚旧程序并尝试重新启动。备份、下载暂存与安装日志位于 `data/updates/`，不会进入发行包。

V2.1.0 以前的版本需先手动解压新版并保留 `userdata/`；安装本版后，后续正式版即可使用内置更新。

## 目录和迁移

| 目录 | 内容 |
| --- | --- |
| app/ | 服务、协议、网页、图标、窗口发现脚本 |
| scripts/ | 启动、关闭、发行包制作脚本 |
| userdata/ | 面板、工程路径、各工程布局、输入历史、主题等个人配置 |
| data/ | 运行端口和关闭凭证（退出后删除） |
| docs/ | 发布说明 |
| test/ | 开发测试，不进入发行包 |
| dist/ | 本地生成的发行 ZIP 与 SHA256，不进入 Git |

关闭后复制整个文件夹即可迁移。升级时保留 userdata，用新版 app/scripts 替换旧程序。发现根目录旧 panel.json 时会自动迁移；发行包没有旧配置，首次打开为未连接、零变量、默认主题、教程展开。

## 开发和打包

运行 `npm test` 验证协议、TCP、状态切换、数组成员、写入回读、目标切换、滚轮、布局与发布内容。运行 `npm run release` 生成 ZIP 和 SHA256。
发行包由白名单生成，仅收录程序、启动关闭脚本、说明文件；排除用户配置、工程文件、运行凭证、研究截图、Git 和测试目录。Node.js 与 ARM GNU 工具链不随包分发。

Keil 图标用于标识兼容的 µVision 软件，商标属于相应权利人；本工具是独立辅助软件。
官方说明：[UVSOCK 配置](https://www.keil.com/support/man/docs/uv4cl/uv4cl_dg_other.htm)、[独立端口参数](https://www.keil.com/support/man/docs/uv4/uv4_commandline.asp)。
