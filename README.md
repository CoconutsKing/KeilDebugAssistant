# Keil Debug Assistant V1.0

作者：oyhy

V1.0 支持在已配置组件的标题齿轮中重新选择变量及数组下标/成员。保存后保留范围、步长、收藏状态和组件位置大小；更换变量时清除原变量的成员专用范围，不迁移旧变量的目标值切换记录。若只修改原变量的范围，则保留其成员设置。组内数值行的齿轮仍用于该成员的范围设置；要更换整个组件，请使用组件标题处的齿轮。

本地 Git 标签 `v0.1` 保存 V1.0 改动前的源码快照，`v1.0` 标记本次版本。个人面板、运行凭证及研究文件不纳入版本提交。

用于 Keil µVision 的本地变量监视和滑块调参工具。Node.js 20+，无需 npm 安装依赖，不需要修改 MCU 固件。已在本机正在运行的 Keil 调试会话上验证兼容接口只读访问（枚举和浮点数组元素）；实机写入、扩展成员枚举仍待验证。

## 启动

双击 `start.cmd`，或在本目录执行：

```powershell
npm start
```

浏览器打开 http://127.0.0.1:3210 。命令窗口需要保持运行。首次可选择“演示数据”并点击“连接会话”体验。

## 连接真实 Keil

1. 在 Keil 的 **Edit → Configuration → Other → UVSOCK (TCP/IP) Settings** 启用接口，查看实际端口，必要时重启 Keil。界面默认端口 4823 只是初始值，以 Keil 配置为准。
2. 打开工程，在本工具选择 Keil µVision、填写端口并连接。本工具只连接本机，不替你启动、暂停或复位目标。
3. 在 Keil 进入 Debug，本工具持续检查状态。退出 Debug 后显示等待，连接断开时自动重连。
4. 保存 Keil 工程配置，点击“导入 Watch”，输入 `.uvoptx` 文件完整路径。工具读取 WatchWindow 中的 ItemText / Expression，并持续监视该文件。新增 Watch 项保存后自动加入。
5. 对需要调整的变量设置最小值、最大值和步长，点星号加入个人调参面板。拖动滑块，**松开后写入**；也可输入数值点“写入”。界面显示真实回读值。

### 已进入 Debug 后连接

Keil 可能拒绝在 Debug 期间设置扩展模式（状态 10）。工具会保持目标运行，切换到 CALC_EXPRESSION 兼容接口读取数值，支持直接输入数组元素或完整成员路径。枚举值以实际数字显示；指针只读，不启用地址滑块。需要点击写入时才生成数值赋值表达式，再回读结果。

此模式不能自动枚举类成员。需要展开时，请自行在 Keil 退出 Debug，保持工具连接；等待工具检测并启用扩展模式，再进入 Debug。工具不会自动结束或暂停调试。若扩展接口仍不受当前版本支持，会继续使用兼容读取，并显示说明。

网络上的字符串末尾可能省略 SDK 结构体中的预留填充；解析器按实际字符串长度校验，不再强制每个 VARINFO 响应必须满 1060 字节。真正不完整的字段仍会报错。

## 已实现

- Watch 配置导入、文件变化同步新增项、手动添加变量。
- 轮询实时值、单变量错误、运行/暂停/等待状态、连接断开重试。
- 搜索、收藏面板、滑块和数字输入、范围校验、整数类型校验、写后回读。
- 数组、结构体和 C++ 类成员浏览：变量卡片点击“浏览成员”，或添加时输入根变量后浏览。可逐层展开并选择叶子成员，数组每页 64 项；可直接输入 `motors[2].pid.kp`、`samples[3][5]`、`controller->gain`、`app::controller.gain` 等完整路径。选中后保存为独立监视项，可设置范围并写入。
- 面板自动保存到本目录 `panel.json`；JSON 导入导出不包含实时值，也不会自动写入硬件。
- 本地 HTTP 只监听 127.0.0.1，校验 Host、Origin 和写请求客户端标识。

## 下拉选择变量与数组数值

点击“添加变量”，从“工程变量”下拉列表选择变量；数组会出现元素下拉列表，类/结构体会出现成员下拉列表，可继续逐层选择。选择后显示 Keil 实时回读，设置范围并保存即可加入监视。筛选输入框仅用于过滤候选项，无需输入完整表达式。

变量名称、数组长度和成员类型从当前 `.uvoptx` 对应的 `.uvprojx` 编译输出 `.axf` 的 DWARF 调试信息读取；实际数值仍从 Keil 读取，不直接按 AXF 地址读写内存。须先编译并启用调试信息，确保本地 AXF 与当前加载的固件一致。需要 `arm-none-eabi-readelf` 在 PATH 中（本机已安装）。缺少工具链或调试信息时，列表退回到已配置的 Watch 变量，并提示原因。

保存数组、类或结构体后，面板自动展开其中可识别的成员，每个数值成员都有独立数值输入、滑条、加减按钮和范围设置。无需逐个添加 PID 的 kp/ki/kd。多维数组、结构体数组可递归展开，单组最多 512 行、8 层；超限会提示，应单独选择子数组继续观测。指针保留只读指针项，不自动解引用任意地址。

鼠标悬停在滑条上，滚轮向上增加、向下减小，无需点击聚焦；连续滚动按 120 ms 合并请求，并在写入结束后读取实际值。拖动滑条松开也会写入。加减按钮使用该行步长，整数变量至少按整数步长调节。每行齿轮可保存该成员自己的最小值、最大值、步长；组标题齿轮设置整组默认范围。

新建变量保存成功后，范围、步长、收藏状态会成为下一次新建的默认设置，保存在 `panel.json` 中，重新启动仍有效。编辑已有变量不改变新建默认值。删除按钮立即移除整个组；删除状态保存在配置中，Watch 文件再次保存时也不会把该项重新加回来，可从下拉列表重新添加。

数值通过 Keil 逐项读取，不是同一时刻的原子快照。优先刷新屏幕内的组，后台组较低频率读取；每行显示数据年龄。成员较多时首次读齐及完整刷新周期会变长。界面不再因鼠标焦点而暂停刷新，也不会重建正操作的滑条。

使用 AXF 类型信息时，兼容模式下也可下拉选择数组和类成员，无需为此退出 Debug。目录包含具有具体存储位置的全局及文件静态变量，不包含栈上局部变量。当前自动使用 `.uvprojx` 中第一个目标的输出配置；多目标工程需确认该配置就是正在调试的目标。未识别的类型、匿名成员、继承成员等复杂情形可能仍需使用调试器支持的完整路径。

## 当前边界

- **尚不能直接枚举 Keil GUI 中未保存的 Watch 列表。** `.uvoptx` 导入不是对 Watch 窗口控件的实时抓取；保存配置后才会同步。文件同步只新增，不自动删除已配置的面板项。
- 实时性是轮询，不是硬实时。间隔 100–10000 ms；变量逐个读取，变量多时实际周期更长。
- 硬件运行中是否支持访问，由 Keil 版本、芯片、探针和配置共同决定。不支持的操作显示错误，不会偷偷暂停 MCU。
- 局部变量在作用域外、优化掉的变量以及不可写表达式可能不可用。推荐全局/静态数值变量。支持名称、类/结构体成员、固定下标、指针成员和命名空间，暂不支持任意表达式、函数调用、字符串写入或结构体整体写入。类成员可见性取决于 Keil 提供的调试信息；无法枚举时可输入完整路径尝试。单层类成员枚举最多 256 项，数组可分页选择任意合法下标。
- Keil 的数值显示如果带有单位/枚举文本等非纯数字，仍能显示，但不会启用数值滑块。
- 写入按变量逐项执行，不提供多变量原子事务，也不强制数值落在步长网格上。步长用于滑块和输入框增减。
- 演示模式和真实会话共用面板配置。请按工程分别导出面板，切换工程后载入对应文件。
- 服务启动后即监视已保存的 `.uvoptx` 路径；连接真实 Keil 仍需用户点击连接。默认启动不写任何目标变量。

## 关闭工具

双击 `stop.bat`，或在本目录执行 `node stop.mjs`。脚本根据 `.keil-runtime.json` 中当前实例的端口和随机凭证发送退出请求，释放服务端口并断开本工具的 Keil 连接，不退出 Keil、不停止 MCU，也不结束其他 Node.js 程序。浏览器页面可自行关闭。支持通过 `PORT` 设置的自定义端口；服务正常退出会删除运行信息文件。修改前启动的旧版本没有退出接口，需要在原启动窗口按 Ctrl+C 关闭一次。

## 实际值刷新与自由排版

实际值显示与输入框焦点分开处理：数字输入按回车或点击“写入”、滑条松开或滚轮调节后，回读结果立即更新，同一变量在其他组件中的显示同步刷新，无需点击空白。仅仅聚焦滑条不会阻止后续采样刷新；正在输入且尚未提交的数字会保留，旁边实际值继续更新。

点击“编辑布局”，每个变量卡片或整组参数组件都会出现标题旁移动柄 ⠿ 和右下角缩放柄 ◢。拖动后松开自动保存；也支持聚焦操作柄后按方向键微调，Shift 加方向键加大移动量。点击“完成排版”返回正常调参；编辑布局期间组件内部参数控件不可操作。组件可自由重叠，大组件内部滚动，不会隐藏其他成员。

“恢复自动排版”返回自动网格并清除自定义位置和大小。自定义布局保存在 `panel.json` 中，刷新、重新启动仍有效；面板导出/导入也包含布局。搜索或只看收藏时保留组件之间的相对位置，并将可见组件移到视图起点；屏幕较小时可横向滚动画布。布局单位为像素，位置按 8 px 对齐，最小尺寸 280 × 180 px。

## 两个目标值一键切换

每个数值行都有“⇄ 切换到 …”按钮，数组元素和类/结构体成员分别记录。首次成功写入不同数值后，保存修改前实际值与新输入值；按一次切到前者，再按一次切回后者。手动输入、滑条、滚轮或加减按钮写入新值时，用当前选中的目标值和新值组成新的一对。普通采样不改变这两个输入目标；失败写入不改变记录。

例如实际值为 0，输入 10 后按钮切换 0 ↔ 10；此时输入 20，则变成 10 ↔ 20。如果正在 0 这一侧时输入 20，则变成 0 ↔ 20。同一变量的多个组件共享记录，记录按工程区分，演示模式独立保存，重新启动后仍保留。按钮会检查当前可写状态与范围；切换目标超出范围时禁用，调整该行范围后即可使用。

## Keil 状态 13 的写入确认

写入数值使用明确的整数进制或浮点字面量，避免受 Keil 默认进制影响。赋值操作返回状态 13 时，仍执行独立的只读回读；只有实际值匹配请求值（包含 float32 的表示转换）才视为目标已达到，并保留内部诊断信息。实际值不匹配时仍报“写入未确认”，并显示真实回读值。回读阶段遇到瞬时状态 13 时最多重试两次，只重读，不重复赋值。此处理不代表所有状态 13 都可忽略，也不能代替具体硬件上的写入验收。

协议依据 Keil UVSOCK / UVSC 头文件的 packed 32 字节帧头、扩展栈模式、EVAL_WATCH_EXPRESSION 和 VARIABLE_SET。研究用头文件放在 research 中，不作为产品依赖，也不重新分发 Keil DLL。
