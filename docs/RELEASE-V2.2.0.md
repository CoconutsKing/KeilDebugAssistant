# Keil Debug Assistant V2.2.0

- 已添加的数组及数组成员可直接修改索引，支持左右切换、整个数组和嵌套维度；保留组件布局、范围、步长及成员勾选。
- 侧栏收起后自由布局整体居中，原坐标与大小保持不变。
- “变量监视”旁可收起全部顶部设置，只保留监视区域；状态自动记忆，可随时展开。
- 选择窗口后一键进入 Debug 并运行，已暂停时继续运行；显示进度与错误，支持取消和多窗口隔离。需要已编译工程、正确的 Keil 调试器设置以及连接并供电的开发板。
- 保留滑条、滚轮、上次值切换、十六进制、批量成员、PID 参数保存恢复与 GitHub 静默更新。

92 项自动化测试及网页操作验证通过。本次真实 Keil 进入 Debug 被目标 DLL 取消，手动启动也相同，尚未完成 ST-Link 的成功启动 / Run 验证。

发行包仅含程序与说明，首次解压为未连接、零变量、默认主题；不包含个人面板、工程路径、参数保存记录或运行凭证。升级时保留 `userdata/`。
