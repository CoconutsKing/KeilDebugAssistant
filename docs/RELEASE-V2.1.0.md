# Keil Debug Assistant V2.1.0

新增后台静默更新和数组 / 结构体参数保存恢复，并修复批量恢复时的 Keil 请求超时。

## 新功能

- 左侧“软件更新”提供自动更新开关、立即检查和手动更新。默认在启动约 15 秒后检查，此后每 6 小时检查一次，设置自动记忆。
- 连接 Keil 时只在后台下载；手动断开并结束面板编辑后，安装并重启工具。版本检查、下载和解压不占用 Keil 采样锁。
- 更新包校验 SHA256、ZIP 路径及包内版本；保留用户配置，新版启动失败会回滚并尝试启动旧版。
- 数组 / 结构体组件增加“保存当前数据”和“恢复已保存数据”，按工程保存当前显示的数值成员。退出 Debug、重启工具后仍保留，可用于重新写入已调好的 PID 参数。
- 恢复前检查成员、类型、范围和可写状态，逐项写入并回读确认，显示进度及部分失败的完成数量。

## 修复

- 数值写入改用表达式赋值，避开扩展 Watch 写入接口的长时间等待，修复恢复数组 / 结构体参数时的请求超时。
- 保留扩展成员浏览、独立回读与状态 13 校验；真正超时时停止操作，不重复发送未确认的赋值。

## 使用和升级

1. 下载 `KeilDebugAssistant-v2.1.0-windows.zip` 并解压，安装 Node.js 20 或更高版本，双击 `start.cmd` 启动。
2. 旧版用户先用 `stop.bat` 关闭工具。保留原 `userdata/`，再替换程序文件；此目录包含面板、PID 保存数据、布局、历史和主题。
3. V2.1.0 以前的版本需要手动升级到本版，之后可在左侧“软件更新”使用自动或手动更新。

安装包不包含作者的个人配置、工程路径、PID 数据、运行凭证或更新缓存。首次解压启动为未连接、零变量和默认设置；GitHub 更新检查不需要登录或访问凭证。
