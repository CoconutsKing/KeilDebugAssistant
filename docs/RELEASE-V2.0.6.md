# Keil Debug Assistant V2.0.6

修复侧栏收起卡顿，并调整切换按钮图标。

- 点击后立即收起 / 展开，界面不再等待 Keil 采样或设置保存。
- 按钮采用三条横线，左下方显示方向箭头：左箭头表示收起，右箭头表示展开。
- 快速连续点击以最后一次选择为准，刷新后记忆侧栏状态；主题和教程设置同样即时应用。
- 界面偏好保存独立于 Keil 读取，文件保存按顺序进行，保留原面板、范围、成员选择、布局和输入历史。

55 项测试通过；完成目标读取阻塞下的设置保存测试，以及浏览器切换、箭头方向、连续点击和刷新记忆验证。

解压后双击 start.cmd 启动，stop.bat 关闭。需安装 Node.js 20+。发布包不含个人配置或运行凭证，首次打开为全新状态。升级时保留原有 userdata 目录即可保留配置。
