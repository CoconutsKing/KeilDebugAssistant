# Keil Debug Assistant V2.0.9

优化数组成员配置提示和操作按钮排版。

- 在成员下拉框旁增加提示：“不选具体成员，默认调试整个数组；可用批量选择限定范围。”结构体同样提示默认调试全部成员。
- “浏览此变量的成员”和“批量选择显示成员”采用等宽、等高按钮，统一字号、间距和颜色。
- 保留单元素选择、成员浏览、数组翻页及已有批量筛选范围；未改动变量采样和写入逻辑。

59 项回归测试通过。浏览器验证两个按钮等宽且均高 42 像素，成员提示在数组翻页后保留；原有成员浏览、单元素选择和 15 项批量配置正常。发行包通过解压启动 / 关闭检查，首次启动为全新状态，不含个人配置、工程文件或运行凭证。

解压后双击 start.cmd 启动，stop.bat 关闭。需安装 Node.js 20+，无需安装 npm 依赖。升级时保留原有 userdata 目录即可保留面板和布局。
