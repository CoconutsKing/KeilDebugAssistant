# Keil Debug Assistant V2.0.1

修复 V2.0 变量配置更新、删除卡顿，以及读数被窗口扫描中断的问题。

旧版在串行采样中扫描 Windows 进程，实测每次约 5 秒，导致 Keil 读数与界面请求一起等待。现已将窗口识别改为可取消的后台任务，按扫描完成时间计算间隔，并合并重复扫描。当前会话持续采样，窗口列表显示识别进度。

瞬时读取失败时保留上次成功值和时间，同时显示错误并禁用写入；读取恢复后自动刷新。

当前 ST-Link 环境实测：后台扫描期间配置更新和删除响应约 6～16 ms，5 秒内连续获得 10 次新读数，最近读数最大间隔约 442 ms。额外观测变量正常读取，测试后恢复原面板。首次识别窗口仍可能需要几秒，但不会阻塞已有会话采样。

本次 40 项自动化测试通过，新增慢扫描期间 HTTP 配置、删除、连续采样、瞬时错误恢复、扫描取消和过期结果隔离回归。

下载 ZIP，关闭旧工具后替换程序，保留 `userdata`。需要 Node.js 20+；双击 `start.cmd` 启动。新包不含个人面板、工程路径、调参历史和运行凭证。
