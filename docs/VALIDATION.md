## ST-Link 实机

- 两个真实 Keil 窗口同时打开，分别使用独立端口。第一个没有进入 Debug 时，自动连接第二个已进入 Debug 的窗口，工程和 Watch 来源正确。
- 手动锁定未进入 Debug 的窗口时保持等待，不误选另一个窗口。
- 第二个退出 Debug、第一窗口进入 Debug 后，自动切换成功；完成后恢复第二个调试窗口。
- 数组元素写入 0 → 1，立即回读确认；两次目标值切换得到 0 → 1，最后恢复为 0。
- 网页输入框修改结构体数值成员，回车即写入并刷新实际值；完成后恢复原值。
- 数组组件替换为不同成员数量的结构体，保存的布局坐标、宽度和高度保留，超出的成员内部滚动。

本记录反映本次软件回归和现有 ST-Link 环境实测，不代表所有 Keil 版本、芯片、探针和被优化的局部变量都具备相同行为。未处于当前作用域的 Watch 表达式仍会明确显示不可读，不会作为可写变量处理。
