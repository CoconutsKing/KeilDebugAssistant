# Keil Debug Assistant V2.0.7

连接状态一眼可见，随时手动连接和断开。

- 删除“数据源”下拉菜单和演示模式，直接连接 Keil。
- 连接成功：红色“断开连接”按钮，旁边绿灯闪烁。
- 正在连接或等待 Debug：绿色“取消连接”按钮，黄灯闪烁。
- 未连接或失败：绿色连接按钮，红灯闪烁；具体失败原因显示在下方，失败时可停止重试。
- 即使 Keil 正在等待变量读取，也能立即断开。断开后停止读取、扫描和自动重连；重新连接可恢复原面板。
- 教程右上角增加 ×，关闭后刷新仍隐藏；左侧“新手教程”可重新打开。

59 项测试通过，完成浏览器连接、失败、断开、教程关闭记忆与重新打开，以及原有写入回读、上次值切换和进制显示验证。真实 Keil 当前端口拒绝连接时，失败状态与错误提示正确显示；成功状态使用隔离测试目标验证。

解压后双击 start.cmd 启动，stop.bat 关闭。需安装 Node.js 20+。发布包不含个人配置或运行凭证，首次打开为全新状态。升级时保留原有 userdata 目录即可保留配置。
