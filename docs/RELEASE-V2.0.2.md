# Keil Debug Assistant V2.0.2

- 修复选择指定 Keil 窗口后下拉框跳回“自动”的问题；刷新列表、刷新网页和窗口状态变化时保持所选窗口。快速连续操作以最后一次选择为准。
- 切换已识别窗口时复用列表和调试连接，立即显示对应工程路径。重复连接当前窗口不会清空读数、重建连接或重新扫描工程。
- 读取窗口标题中的当前工程路径，仅在信息缺失时查询 WMI；程序启动时提前识别窗口。当前双窗口环境实测首次识别约 0.47 秒，缓存工程切换请求约 5～13 ms。
- 主题改为五个颜色圆点，显示勾选状态，支持键盘与屏幕阅读器，刷新后保留设置。

43 项自动化测试通过，并完成真实双 Keil 窗口的选择、路径切换、列表刷新、页面刷新，以及全部颜色主题点击验证。测试后恢复原先的窗口选择和主题。

关闭旧工具后替换程序，保留 `userdata`。发行包不含个人面板、工程路径、调参记录和运行凭证。需要 Node.js 20+，双击 `start.cmd` 启动。
