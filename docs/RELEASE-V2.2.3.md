# Keil Debug Assistant V2.2.3

修复包含 ErrorFilter 指针的 PID 对象无法复制的问题。不可复制的成员会跳过，其余数字仍可导出。

- 结构体使用 `{.Kp = 1.25f, .Ki = 0.5f}` 格式；结构体数组与嵌套成员保留花括号层级。
- 跳过指针、联合体、非数字和不可读值，显示复制与跳过数量。省略成员按默认规则初始化；数组缺失项以 `{}` 占位，数值元素对应零初始化，后续下标保持不变。
- 默认复制当前对象，也可选择整个父数组；无可用数字或连接 / 会话失效时不生成结果。
- 指定成员格式需要 C++20 及支持聚合初始化的目标类型；带自定义构造函数的类可使用对应参数结构体。
- 同时包含 V2.2.2 的布局修复：组件可拖到画布最左侧，保存 / 刷新后不回弹；折叠侧栏的图标统一居中。

保留布局、侧栏、滑条、滚轮、参数保存恢复和后台更新功能；复制只读，不改写开发板数据。
