# Keil Debug Assistant V2.0.8

将 Keil 连接按钮和状态灯移到连接区最左侧，在窄窗口中也能直接看到。

- 连接 / 取消 / 断开操作与状态灯前置，窗口选择、刷新、端口和采样间隔跟随其后。
- 空间不足时设置项自动换行；键盘操作顺序与界面顺序一致。
- 保留原有连接颜色、闪灯、错误提示、变量调参和教程关闭功能。

59 项回归测试通过，并已在实际连接 Keil 的窄窗口中确认按钮可见、变量继续读取。发行 ZIP 解压后通过启动 / 关闭验证，首次启动为未连接、零变量、默认设置；不含个人配置、工程文件或运行凭证。

解压后双击 start.cmd 启动，stop.bat 关闭。需安装 Node.js 20+，无需安装 npm 依赖。升级时保留原有 userdata 目录即可保留面板和布局。
