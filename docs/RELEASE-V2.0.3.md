# Keil Debug Assistant V2.0.3

修复网页修改变量后，再从 Keil 修改时网页实际值不再同步的问题。

- 持续采样和写后回读使用独立表达式读取实际数值，避免扩展 Watch 的旧缓存；继续保留数组、结构体和类成员支持。
- 实际值、滑条、数值框和写后提示持续同步，输入框无需失去焦点。
- 修复 Keil 返回十六进制时数值框为空、滑条位置错误的问题。
- 保留未提交的输入草稿、上次值切换目标、范围、布局和主题设置。

验证：45 项自动化测试通过；使用 ST-Link 验证兼容/扩展模式下网页写入、独立 Keil 修改及目标运行时持续变化，扩展模式实测约 394 ms 同步外部修改。

解压后双击 start.cmd 启动，stop.bat 关闭。需安装 Node.js 20+。发布压缩包不含个人面板、工程路径、输入历史或运行凭证；首次打开为全新初始状态。升级时可保留自己原有的 userdata 目录。
