# Keil Debug Assistant V2.0.4

增加整型变量的十六进制显示复选框。

- 在整型数值旁勾选“十六进制”显示 `0x…`，取消后显示十进制；数组元素和结构体成员可分别选择。
- 鼠标悬停实际值，可同时查看十进制和十六进制。负数显示为 `-0x…`，64 位整数精确转换。
- 选择随工程面板保存，刷新、重启、导入导出后保留。浮点数没有此选项。
- 仅改变显示，数值输入和滑条仍按十进制调节，已有目标切换、实时同步、范围和布局保留。

49 项自动化测试通过，并使用 ST-Link 实测显示切换、持续更新和刷新记忆。

解压后双击 start.cmd 启动，stop.bat 关闭。需安装 Node.js 20+。发布压缩包不含个人面板、工程路径、输入历史或运行凭证。升级时保留自己原有的 userdata 目录即可保留配置。
