# Keil Debug Assistant V2.2.1

数组组件新增“复制 C++ 数组”。选择复制范围后，一键读取整个数组并复制为 `{1, 2, 3}`；多维数组保留 `{{1, 2}, {3, 4}}` 的嵌套格式，结构体数组及成员中的数组也保留各层花括号。浮点数使用 `f` 后缀，64 位整数保留精确十进制值。

- 支持当前子数组、所属整个数组和当前对象；读取包括未勾选显示的成员，单次最多 16384 个数值、16 层嵌套。
- 分批读取、显示进度、可取消；不会写入目标，也不修改布局、成员勾选、历史或已保存参数。运行中的数值可能变化，需要固定快照时请先暂停目标。
- 任一成员不可读、含指针 / 联合体或超出限制时明确报错，不生成残缺数据。浏览器限制自动复制时提供完整文本窗口。
- 包含上一轮的组件内数组索引切换、布局居中、顶部设置折叠、一键进入 Debug 并运行；原有滑条、滚轮、保存恢复与 GitHub 后台更新继续保留。

100 项自动化测试通过，并验证网页复制 / 粘贴及剪贴板限制下的文本回退。复制读取验证使用隔离 UVSOCK 目标；本轮未改写实际开发板变量。一键 Debug 的真实硬件验证限制见验证记录。

下载 `KeilDebugAssistant-v2.2.1-windows.zip` 解压，安装 Node.js 20+ 后双击 `start.cmd`。发行包为未连接、零变量的全新状态，不包含个人配置、工程路径、保存参数或运行凭证；升级时保留 `userdata/`。
