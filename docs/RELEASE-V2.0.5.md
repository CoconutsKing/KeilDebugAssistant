# Keil Debug Assistant V2.0.5

支持批量选择数组、结构体中要显示的成员，减少调试读取量。

- 新建数组 / 结构体时点击“批量选择显示成员”；已有组件点击“选择显示成员”。可搜索名称或类型、全选 / 清空当前结果、逐项勾选。
- 未选成员不显示，也不参与该组件的周期采样。全部取消后暂停该组件的读取；其他单独添加的元素不受影响。
- 保留原来的具体元素 / 成员下拉和浏览功能，仍可单独添加某个元素。
- 选择随工程面板保存，支持导入导出；范围、步长、十六进制选择、输入历史与组件布局保留。
- 隐藏兼容读取、固定窗口和后台识别等正常提示，只在连接区显示错误和警告。

单个批量列表沿用最多 512 项、8 层的展开范围；更大对象可先选择子数组或成员再批量勾选。旧配置默认继续显示全部成员。

52 项自动化测试通过，并完成浏览器交互验证；模拟 UVSOCK 目标核对了隐藏成员不会被后台读取。

解压后双击 start.cmd 启动，stop.bat 关闭。需安装 Node.js 20+。发布包不含个人面板、工程路径、输入历史或运行凭证。升级时保留自己原有的 userdata 目录即可保留配置。
